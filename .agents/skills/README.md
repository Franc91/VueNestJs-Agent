# Supplementary skills (not in this repo)

Skill **content** is installed into this folder by `install-supplementary.ps1` / `install-supplementary.sh` (or commands in `.cursor/specialists/skills/install.md`).

Run from `code/` after copying the agent bundle:

```powershell
..\VueNestJs Agent\install-supplementary.ps1 -TargetPath .
```

Verify: `npx skills list`
